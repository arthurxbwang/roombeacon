# V5 签到界面与提前结束关闭

2026-09-21。用户要求去掉公共门牌的提前结束操作，避免门外人员结束正在使用的预约。

## 行为

- 门牌与 Control 预览删除提前结束及确认释放入口，精简「签到与释放」、重复品牌与记录说明。签到使用图标胶囊按钮，保留服务器结果、必要保护提示及截止时间。
- `POST /api/meeting-rooms/usage/end` 保留凭证认证，合法旧请求返回 403，不写入会议状态；无凭证仍返回 401。`can_end` 字段保留兼容并恒为 false。
- 旧 `end_requested`、提前结束类型的 `checking` 转为保护，不调用飞书；已发出请求的 `releasing` 保留原有不重试／待核实处理，历史完成记录不变。
- 未签到自动释放继续使用 `NOT_CHECK_IN`，签到和逐实例保护条件保持，其他房间继续使用官方 V4。

## 验证

先以回归复现合法旧请求及旧队列仍可执行，再修改。Ruff 通过；正确 backend 目录运行 pytest：184 项通过；隔离前端 npm ci、构建和 Chromium 70 项通过。

覆盖认证拒绝、已签到预约不被结束、旧队列不写飞书、未签到释放原有边界、签到提交／重复点击／失败保护、Control 回执、V4 默认、720／800 高度三列内容底边对齐。模拟签到截图仅用于布局检查，不充当真实会议验收。

## 部署与回退

目标为现有独立 Control 10.0.24.208，发布代码从 GitHub codex/v5-control-release 获取。部署前要求没有活动监控／释放实例；备份 systemd、Nginx、开关及凭证指纹，保留策略、记录与全部绑定。准确 SHA、实机和全房间核验待部署后补充。

回退时恢复部署备份内 systemd drop-in 和 Nginx 配置，nginx -t 后 daemon-reload、重启 room-display 并 reload nginx。保留全局释放暂停直到核验完成；回退旧版本会重新开放提前结束，因此仅故障恢复使用。
