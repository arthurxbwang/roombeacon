## 灯光（0.2.2 历史测试，颜色与熄灯解释已被纠正）

新固件 `ro.ys.gpio.indexes=154,148,147,116`，前三路均为输出、初始值 `111`，第四路 `GPIO116` 初始为 `0`。旧机第四路为 GPIO137；本次不写第四路，也不改 GPIO 方向、权限或系统固件。

只对前三路做限定测试：`100 → 010 → 001 → 110 → 000`，各保持约 8 秒，并在退出时恢复 `111`。全部写入和读回一致。颜色按 RGB 接线预期分别为红、绿、蓝、黄、灭；**现场色相、亮度、左右灯一致性仍待用户反馈**，读回成功不能代替肉眼确认。

Android 0.2.2 增加完整型号与固件字符串白名单，保留旧机支持，拒绝型号相同但固件不同的设备。灯控仍默认关闭，本机经原生密码维护界面启用用于授权测试。

普通 APK 进程在独立灯控测试页验证：

| 场景 | 读回结果 |
| --- | --- |
| busy / 预期红 | 100 |
| free / 预期绿 | 010 |
| soon / 预期黄 | 110 |
| unknown、未知协议 | 000 |
| 渲染线程阻塞 6.5 秒 | 读取超时后 000，恢复后 010 |

此阶段无需 ADB 代写灯值、run-as、root 或 chmod。第四路始终读回 0。断网验证仅为移除测试通道，未物理拔网线；失联须由轮询或超时发现后熄灯，不是瞬时响应。强杀进程或硬件写入故障不能保证熄灯。
