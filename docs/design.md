## 1. 版本

V1 是经典布局，V2 引入比例自适应、只列本场和下一场、12 小时时间轴、全屏。V3 去掉预约占位，增加真实官方签到码，右侧仅未来两场（缓存范围内跨日），标题“后续会议”。保留三个版本选择，默认仍是 V2，未经用户要求不改默认。

## 2. V3 视觉

- 深色夜空背景与浅色冷灰白背景，按每间会议室所在城市日出日落自动切换。
- 空闲翡翠绿、15 分钟内即将开始琥珀橙、使用中红色、状态未知灰色。
- 大字状态“使用中 / 即将开始 / 空闲可用”，与核心时间字号对应，向上扩大且保持原下缘。
- 全屏状态色边框；左侧原重复竖线已移除，保留透明边框维持几何位置。
- 左侧主信息旁放签到码与公司插画，不堆入右侧；无独立背景框，二维码白静区保留。
- 主区域突出状态、倒计时、主题和组织者；去掉“欢迎使用”。右侧空态不伪造设施信息。
- 12 小时轴为当前整点前后各 6 小时，已约红、已结束灰、可约浅绿；未知/停用不显示绿空档。
- 容器查询和 cqw 布局需较新的 WebView；窄屏允许滚动保持内容可达，不承诺任意小屏无滚动。

## 3. 签到

用户提供的官方飞书房间签到链接在服务器环境中按 room_id 配置。服务器离线生成高纠错艺术码，中心汽车/无人机装饰由链接哈希确定，不随机变化，不将公司宣传码替换为签到码。

公司原始 GIF 的顶部用作品牌动画，裁切掉其宣传二维码部分，降低饱和度；黑色主题采用仅限 .dark-brand 的 CSS 滤镜，防止影响全页面。红/绿表示预约状态，不表示是否签到。

未来真机必须测试明暗主题、不同手机和角度扫码。历史扫码验证不能代替新屏幕实测。

## 4. 硬件取舍

- 工业研华 TPC-110W 被用户因约 9900 元报价排除。
- 安卓 RK3566 商显曾评估为性能可用，4GB 优先，但未购买或实测。
- CM4 13.3寸屏可复用 H5；1GB 仅适合样机评估，2GB/4GB 更有余量，未最终选定。
- 当前最终方向为 Tab S8 APK 与 ESP32-P4 10 寸屏对比，先规划、不实施。
- PoE 分离器只能分出电源/数据，不能给没有网卡的板增加以太网能力。具体供电必须匹配整机，不凭芯片型号选电压。
- ESP 需原生图形固件，不能直接运行当前 Vue 网页；不因为功能简单就承诺比 Android 稳定。

硬件型号、报价与供应信息为本会话历史评估，不是持续更新的采购承诺；购买时重新确认 SDK、芯片修订与功耗。
