# ADR 0002：稳定 Android 外壳与服务器页面

日期：2026-09-20。状态：首版实施。

用户授权编写 APK 并在 RK3568、Android 11、2GB、1280×800、WebView 106 样机安装测试；独立服务端和飞书应用正在申请。

采用 Kotlin Activity + 系统 WebView，minSdk 26，compile/targetSdk 35。界面、业务和设备凭证绑定复用 H5。APK 不含完整业务页面，不捆绑 Chromium，不下载执行 dex，不保存飞书或主控凭证。

外壳保存服务器 origin、方向及维护密码摘要，DOM storage 保持 argus_room_* 键。禁止应用备份；更换 origin 时清除旧网页存储，重新绑定。页面通过既有接口发送单会议室 Bearer 凭证。

正式版仅 HTTPS，精确限制 scheme/host/port；禁止外部导航、文件访问、混合内容及证书绕过。调试版只额外允许 localhost/127.0.0.1 HTTP，供 adb reverse 隔离测试。不开放 JavaScript 原生接口，健康探测由原生 evaluateJavascript 发起。

主页面失败、超时和渲染退出显示原生故障覆盖层并退避重试；健康探测超时重建 WebView。维护状态暂停自动恢复。提供可选 HOME 入口及 Device Owner 锁定，管理员手动启用；不自动恢复出厂或设置设备所有者。普通 Activity 不保证开机启动，断电上电由固件决定。

网页检测构建标识以支持服务器更新。HTML 重新验证、旧哈希资源保留、原子发布与回退须同时成立。兼容基线为 WebView 106；系统安全更新独立维护。

断网冷启动显示原生故障页，不承诺持久离线日程。现有凭证 30 天有效期、同房间重新签发使旧凭证失效的限制不变。逐设备身份、续期和灯条 SDK 后续实施。调试 APK 不作为正式发布包，签名密钥不入库。

参考：https://developer.android.com/develop/ui/views/layout/webapps/handle-termination

## 本地灯控增补（2026-09-20）

用户授权在现有样机实现本地状态同步。维护页显式启用，仅匹配已测试的型号与固件；默认关闭。原生每秒读取主文档 `main[data-terminal-protocol="1"]` 的 `data-terminal-state`，只接受 `free`、`busy`、`soon`，其余熄灯。此契约不依赖可见中文、主题颜色或 DOM 排版；中控预览不输出有效灯控状态。仍不开放 JavaScript 原生接口，也不传设备令牌到灯控模块。

GPIO 固定白名单 154/148/147，分别按已观察的 RGB 接线使用；不访问 IO4/继电器，不更改系统权限。空闲绿、使用中红、即将开始黄；过期、停用、失联被页面判定未知后熄灯。原生加载、暂停、维护、失败、渲染退出立即尝试熄灯；单次页面状态读取超过 3 秒时熄灯并重试，迟到回调不能恢复旧灯色。所有写入均读回核验，失败尝试关闭三路并记录不含业务数据的错误。

首次需要升级 APK 到 0.2.0；后续网页维持协议 1 即可独立更新。网页轮询与请求超时决定网络故障的发现延迟，不能宣称拔网线瞬间熄灯。应用被强杀、原生主线程卡死或硬件拒绝写入时无法保证灯自动熄灭；硬件 watchdog 和固件级失效保护另行实现。

0.2.1 进一步将原生加载地址从固定 `/?version=v3` 改为根入口 `/`，由 H5 管理默认版本（当前 V4）及已有版本选择，避免未来页面版本变化要求修改 APK。显式 V1/V2/V3 URL 和 `argus_room_version` 键继续兼容。
