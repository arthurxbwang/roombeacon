# ADR 0004：V6 集中设备管理

状态：2026-09-22 用户批准实施并上线；Issue #10。角色仅管理员、只读。

单主服务器使用独立 SQLite（WAL、事务、持久目录）保存设备、权限、配置历史和审计，Redis 保持日程与 V5 状态。地区节点协议先预留，当前唯一可调度节点为 central；不宣称异地集群已上线。

设备身份与 Wi-Fi/以太网 MAC、SN 分离。Android 首次启动生成随机设备 ID 和独立秘密，使用 Android Keystore 加密保存；短码由服务器唯一索引分配，仅作为辅助核对信息。网络切换不改变身份。

注册是认证建立的必要引导接口：首次请求携带设备自行生成的注册凭证，只允许创建隔离的待激活记录，限流并限制待激活总量，不允许读取会议数据。首次自报 SN/MAC 不代表可信硬件证明；管理员结合现场短码和资产信息认领后才授予业务权限。重复 ID 必须匹配已存凭证摘要；撤销后不可自行重注册或用相同 SN/MAC 恢复权限。后续厂商批量交付可增加预登记证书。

OAuth 入口、回调及会话建立是管理员认证的引导接口。回调校验浏览器绑定的一次性 state，服务端换取身份；新飞书用户默认为待授权，使用现有主控凭证建立管理会话后手动授予角色。不把应用可用范围当管理员权限。

原生管理凭证不提供给网页。服务器签发短期、绑定设备及配置版本的网页会话，原生仅为受信 HTTPS origin 写入 HttpOnly Cookie；网页通过既有 API 获取缓存。设备撤销/换房立即使旧网页会话失效。V6 沿用 V5 按房间控制的签到规则，设备凭证不能修改规则，设备管理心跳不替代真实网页业务心跳。

配置采用期望版本/实际版本与回执；并发修改比较版本，历史配置可发布为新版本，刷新命令以递增版本标记。方向、灯控及页面选择在原生应用后报告。Wi-Fi/有线信息分别展示，PoE 仅表示供电方式，应用按 Ethernet 处理网络。

正式 APK 内置生产主域名，不默认允许更改 origin；中央节点扩展字段预留，未来可信节点切换另做协议版本升级。普通 APK 不保证安装后自动启动或自动获取 Device Owner；实机启动恢复、网络和系统权限按实际交付能力记录。

旧 API、rooms:*、ROOM_DISPLAY_* 和 argus_room_* 保留。V6 通过新的数据库、Cookie 与接口增加能力；旧设备凭证不批量轮换，V5 写入白名单不扩大。发布必须记录准确 SHA、数据库与配置备份及旧后端/前端回退目标。
