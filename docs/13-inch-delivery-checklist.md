# 13.3 寸量产门牌逐台交付记录模板

关联：[采购到货与分批部署计划](../plan/procurement-rollout-20261011.md) · [Issue #88](https://github.com/arthurxbwang/roombeacon/issues/88)。更新日期：2026-10-11。

每台设备建立一份记录。**安装成功不等于交付通过**；设备在线、配置回执、现场可见画面、维护与真实供电恢复分别验收。全部项目初始为“未验”，没有实际证据时不得提前勾选。

本模板不包含真实设备标识、人员姓名或凭证。真实 SN、MAC、IP、设备 ID、短码及原始回执保存在受控台账；仓库只保留空白模板和脱敏证据编号。不得填写设备令牌、管理员密码、SSH 私钥、签名私钥或未脱敏响应。人工确认和自动回执分别填写，厂家报告、隔离测试与本型号实机结果不得互相替代。

## 7. 单台与少量试点共用长稳观察（#10 / #3）

#10判断设备／网络恢复，#3判断业务行为，共享脱敏证据但分别给结论。设备或单身份72小时试用基线可以先开展，不能自动勾选完整T37；其核心场景、多组织者与来源前置仍须满足，用户暂缓项保持暂缓。
