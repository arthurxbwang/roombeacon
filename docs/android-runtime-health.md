## 原因和修复

灯控写入或读回失败时，RoomLight 会报告故障，MainActivity 将它保存为管理错误。原代码恢复成功只重置 RoomLight 内部标记，没有清除外部错误，可能持续影响后台就绪和业务主控校验。修复改为故障转换回调：真实写入和读回成功后清除灯控来源错误；配置、网页会话和灯控错误分别保存，灯控恢复不能清除其他来源的异常。不存在接口、未识别接线或初始化失败不冒充恢复。

原配置回执只在页面加载完成时更新。之后的加载失败、渲染退出或无响应仅显示本地遮罩，后台管理仍可显示设备在线和旧配置已应用。修复增加独立运行回执，管理连接、配置应用、页面响应、数据状态与灯控分别显示。

WebShell 只在当前 WebView、当前加载代际、同源主文档的真实 JavaScript 探测成功后报告页面 ready；单独 onPageFinished 不作为健康证据。探测读取 app、既有主文档终端状态及 H5 发布标识，不读取会议内容、人员姓名、URL、Cookie 或设备令牌。配置回执仍表示配置已经应用，持续健康另行判断。

## 协议与管理展示

`metadata.runtime` 是可选协议 1：

- `page_state`：waiting／loading／ready／failed／paused。
- `page_error`：固定网络、HTTP、TLS、渲染、超时、无响应、初始化及访问拦截类别，正常为空。
- `page_age_seconds`：单调时钟计算的最近真实探测年龄，无采样为 null；最长 86400 秒。
- `page_release`、`webview`：限制长度和字符的实际版本标识，不接受地址或任意文本。
- `terminal_state`：free／busy／soon／unknown，复用既有网页状态契约。
- `light_state`：disabled／unknown／ok／failed，依据实际灯控读回。

原生超过 35 秒没有有效响应时报告无响应／未知；服务端另叠加管理回执到达后的时间，ready 样本达到 45 秒变为 stale。管理回执过期或时间异常不能显示正常；旧 APK 未上报时显示未知，保留原协议和人工交付验收兼容。

后台台账、设备／部署详情及首装交付区分别显示页面和灯控状态；管理刷新失败时旧健康回执降为过期。已加载但业务数据未知不显示数据正常。新 APK 的自动交付就绪要求新鲜页面与有效终端状态；勾选现场验收不能绕过这些条件。

Activity 暂停时继续原生管理轮询并报告 paused，网页签到心跳、页面探测和灯控活动停止。Android 仍可能终止后台进程，本次没有增加保活服务或承诺后台永不退出。管理运行回执不能替代或授予签到／释放的业务健康。
