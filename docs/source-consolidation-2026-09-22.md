## 代码分析与合并取舍

- 后端：FastAPI 提供凭证保护的展示和主控接口；飞书采集集中进入独立 Redis，终端只读取缓存。失联、过期、撤销维持未知或受保护状态，不生成空闲或签到成功的假结果。
- V5：保留服务器房间白名单、全局暂停、独立操作凭证、实例登记、工作者租约、原子状态转换、终端心跳、发送前核验和单次写入。重复或改期预约依赖对应实例的证据；未知写入结果不自动重发。提前结束兼容接口仍认证后返回 403。
- 前端：保留 V1—V5 兼容、既有浏览器键、页面发布资源核验及 Android 灯控契约；纳入最新无边框签到按钮和倒计时。计时归零仅等待服务器状态，不在客户端宣称已释放。保留新增的签到区溢出回归。
- Android：保留 HTTPS／来源约束、WebView 异常恢复、型号及固件灯控白名单和原生测试。ESP32 仍处于规划阶段。
- 部署：同时保留生产 `/data/roombeacon` 模板和历史兼容模板。模板不代表当前服务器已应用该配置，实际入口为 HTTPS 域名、SSH 8081；部署须单独确定 SHA、目标及回退。
- 文档：统一“提前结束已关闭”、Android 已实施及独立飞书应用的当前说明；保留历史实测日期，避免将旧服务器版本或旧开关状态解释为当前生产状态。

原倒计时测试将每次 API 响应的时间固定在同一时刻，正常轮询会反复重置模拟时钟。本次改为与浏览器受控时钟同步的服务器时间和有效期，分别验证失联和正常轮询跨过释放时间；没有修改业务时间算法。
