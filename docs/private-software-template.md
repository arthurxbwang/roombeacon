- 当前、后续和历史预约不渲染会议名称，也不产生对应的悬浮标题；时间轴继续只展示预约时段。
- 保留会议室名称、容量、时钟、状态、预约时间、组织者、品牌、签到与原有失联保护。
- 左侧用“当前会议／下一场会议”标签连接时段和组织者；后续卡片去掉名称行并调整内边距。保留三列布局及底部时间轴。
- 已认证且已部署保密模板的托管终端日程响应，将每场 `summary` 置空、`titles_available=false`；复制响应，不改中央缓存，继续设置 `Cache-Control: no-store`。
- 这是会议名称的门牌保密设置。组织者姓名依用户要求保留。管理员有权读取完整日程；模板草稿预览在页面上应用隐藏设置。飞书日程、中央缓存和历史独立凭证不由模板重新授予或撤销访问权限。

## 选择、编辑与兼容

管理存储首次打开时仅新增 `builtin-software-private-checkin` 的发布版本 v1 与审计；一次性标记为 `configuration_private_template_v1`。现有设备、房间配置、发布版本及草稿不改写，后台软件模板由两项增至三项。

后台“软件模板”可编辑或复制“签到保密版”。“显示会议名称”关闭即使用保密呈现；该设置也适用于未签到版和历史界面。保存草稿、发布版本均不自动切换设备，需在“设备台账 → 配置与部署”选择准确软件模板版本，并按既有流程确认同房间影响范围和设备回执。

缺失新字段的旧软件版本及日程偏好按 `true` 解释，维持原显示。恢复名称应在新版应用中显式部署原“签到版”历史版本或一个 `show_meeting_titles=true` 的已发布版本。先核对设备回执和实际页面，再视为回退完成。

发布本功能时需先上线同步的后端及 H5，再部署模板；无需改动 APK。不得用回退旧应用代替保密配置回退，旧 H5 / 后端不理解此隐藏设置，可能恢复名称显示。生产发布及真实设备选择须另行确定准确 SHA、目标和回退组合。
